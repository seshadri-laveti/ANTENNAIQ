**AntennaIQ** is an intelligent antenna engineering platform designed to simplify antenna design, RF calculations, electromagnetic simulation learning, performance analysis and research workflows.

The platform combines engineering utilities with AI-assisted analysis to provide a centralized workspace for antenna engineers, researchers and ECE students.

**Developed by:** Laveti Seshadri  
**Branch:** Electronics and Communication Engineering

---

## 🚀 Project Vision

Traditional antenna engineering workflows involve multiple software tools, manual calculations, simulation environments and separate documentation processes.

AntennaIQ aims to bring these activities together in one intelligent engineering platform.

Its vision is to make antenna design, analysis and research more accessible, organized and efficient.

## ✨ Key Features

### 1. Antenna Engineering Dashboard
- Centralized antenna project workspace
- Engineering tools and project navigation
- Design and analysis overview

### 2. Antenna Calculator
- RF and antenna-related calculations
- Frequency and wavelength calculations
- Engineering parameter evaluation

### 3. Antenna Geometry
- Antenna geometry visualization
- Design parameter exploration
- Geometry-based engineering workflow

### 4. HFSS Learning Center
- Introduction to electromagnetic simulation
- HFSS design workflow guidance
- Antenna simulation concepts
- S-parameter interpretation

### 5. Simulation Results Analysis
- S11 response analysis
- Resonant-frequency interpretation
- Return-loss evaluation
- Antenna performance visualization

*Note: The current analytical S11 demonstrations are generated analytically and are not actual HFSS solver results.*

### 6. Antenna Optimization
- Design parameter exploration
- Optimization workflow concepts
- Performance comparison

### 7. Technical Report Generation
- Antenna project documentation
- Simulation result summaries
- Engineering report organization

### 8. AIVA – AI Virtual Antenna Assistant
An AI-assisted engineering interface designed to support:
- Antenna engineering questions
- Design assistance
- Image and geometry understanding
- Simulation-result interpretation
- Engineering guidance
